# Budget Manager

A desktop app for tracking income and expenses.

**Built with:** Python, Tkinter, matplotlib

## Features
- Personal and business accounts
- Add income and expenses by category
- Summary page with totals by category
- Bar and line graphs of transactions and balance

## Running it

Python 3 with Tkinter (included with the python.org installer):

```bash
pip install -r requirements.txt
python3 budget_manager.py
```
